----------------
.env 配置
在项目根目录创建 .env：
QWEN_API_KEY=填写自己的阿里云百炼API密钥（记得去百炼官网点“免费模型用完即停”）
QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
QWEN_MODEL=qwen3.6-flash
QWEN_TIMEOUT_SECONDS=120
QWEN_MAX_RETRIES=2
QWEN_RETRY_BACKOFF_MS=250
QWEN_ENABLED=true
SCAFFOLD_PHASE_COMPLETE=true
注意：
不要提交或分享 .env。
每位开发者使用自己的 API Key。
若不使用真实 Qwen：
QWEN_API_KEY=
QWEN_ENABLED=false
SCAFFOLD_PHASE_COMPLETE=false
----------------
首次执行建库
Set-Location backend
python -m app.ingestion.build_all `
  --embedding-provider hash `
  --promote
构建成功后，应存放在backend/data/processed/qiaopi.db
----------------
打开后端
在项目根目录执行：
Set-Location backend
Remove-Item Env:SCAFFOLD_PHASE_COMPLETE -ErrorAction SilentlyContinue
Remove-Item Env:QWEN_ENABLED -ErrorAction SilentlyContinue
Remove-Item Env:QWEN_TIMEOUT_SECONDS -ErrorAction SilentlyContinue
Remove-Item Env:QWEN_API_KEY -ErrorAction SilentlyContinue
python -m uvicorn main:app `
  --host 127.0.0.1 `
  --port 8000 `
  --reload
后端地址：
http://localhost:8000/api/health
http://localhost:8000/docs
http://localhost:8000/api/generation/qwen-status
----------------
打开前端
另开一个 PowerShell，在项目根目录执行：
Set-Location frontend
npm install
npm run dev
打开：
http://localhost:5173
npm install 通常只需首次运行或依赖发生变化时执行。
