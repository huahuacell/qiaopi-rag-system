# 风格转换测试示例

以下五组内容用于“风格转换 / 侨批体生成”页面的人工验收与演示。
它们只提供现代白话输入，不预设固定答案，避免提示词和模型对单一样例过拟合。

## 示例一：丈夫写给妻子——汇款、思念与生活问候

淑兰：

我到曼谷已经快半年了，现在住处安定，身体也好，你不用担心。店里的事情渐渐顺手，这个月省下三十元，我托可靠的船客带回去。二十元留作家里的米钱和日常开销，另外十元给孩子添衣服。

前几天这里连着下雨，我夜里听见雨声，就想起家门口那条小河，也想起你带孩子在灯下做针线的样子。等生意再稳定一些，我会设法回去一趟。你平日不要太累，有事可以请二叔帮忙。收到钱和信后，记得回信告诉我。

木泉

验收重点：夫妻称谓、寄款分配、思念表达、保重嘱托。

## 示例二：女儿写给母亲——疾病康复与照料安排

母亲：

听姐姐来信说，您前些日子咳嗽得厉害，我心里一直不放心。现在听说已经退烧，能下床走动，我才稍微安心一些。医生开的药要按时吃，不要觉得好一点就停药。

我这次寄回十五元，其中五元买药，五元添些鸡蛋和米，剩下的留着急用。家里的重活先交给哥哥处理，您不要勉强自己去做。天气转凉时记得多穿衣服。等您身体完全好些，请哥哥写信把情况详细告诉我。

女儿月琴

验收重点：晚辈问安、健康关怀、款项用途、请求回信。

## 示例三：兄长写给弟弟——求学、家产与责任嘱托

阿弟：

你上次来信说准备停学回家帮忙，我看后觉得不妥。家里的田租虽然快到期，但可以先同叔父商量续租，不必急着把书丢下。你年纪还轻，能多读几年书，将来办事会更有见识。

我寄回二十五元，十元交学费，八元给母亲作家用，剩下七元留作买书和路费。钱不多，你要仔细安排。家中若有人催你卖田，先不要答应，等我年底回去再一同商量。平时也要照顾母亲，不可因为读书忽略家里的事情。

兄长启明

验收重点：兄弟称谓、求学劝勉、多项金额分配、家产事务。

## 示例四：商号伙伴来函——生意、账款与谨慎托付

陈老板：

上月寄来的货已经收到，共十二箱，其中一箱外包装受潮，但里面损坏不多，我已另行整理。最近码头行情不稳，布匹价格一天一个变化，这批货暂时不要急着降价出售，可以先留在仓里观察几天。

我托汇庄付回货款一百二十元，扣除运费八元，其余账目请按旧账册核对。如果林记商号前来赊货，只能先给少量，旧欠未清以前不要再放大数目。月底请把库存和收款情况列清楚寄来，免得两边账目不一致。

同业绍安

验收重点：非亲属对象、商贸语气、账款核对、风险提醒。

## 示例五：侄子写给叔父——丧事慰问与家庭协助

叔父：

前日收到家信，才知道祖母已经去世，我在外地不能赶回送她最后一程，心里非常难过。祖母这些年一直惦记我们晚辈，如今想到她，许多话都来不及说。

家里的丧事辛苦您和伯父操办。我寄回四十元，二十五元用于丧事，十元给祖父添补生活，五元留给堂妹上学。若费用仍不够，请先向大哥周转，等我下个月领到工钱再补寄。也请劝祖父保重身体，不要因为悲伤而不吃饭、不休息。

侄儿德顺

验收重点：叔侄称谓、哀悼表达、丧事安排、照料长辈与多用途汇款。

## 建议验收方法

1. 分别粘贴五组白话内容并生成。
2. 检查人物关系、金额、用途、地点和事件是否保持一致。
3. 检查不同对象的称谓和结尾是否有合理变化。
4. 手动修改生成结果中的一句话，复制文本并确认复制的是修改版。
5. 点击“装入信封”，完成封装后再“拆开重看”，确认修改内容仍然存在。
